Delegated bypass

03After merge

Secret scanning alerts

AI-detected secrets

Preview · 9 Nov

Actions workflow logs

Scans logs when a run completes, alongside issues, wikis, discussions and pull requests.11

GA · 28 Oct

Public monitoring

Alerts you when your enterprise's secrets leak anywhere on public github.com. Never scans private repositories.12

Custom patterns

Code · find it, then fix it

Code Security

01While coding

CodeQL CLI

Run CodeQL on your machine, or generate results to upload to GitHub.3

02Before merge

Code scanning

CodeQL, or a third-party tool, finds vulnerabilities and coding errors.3

GA · 15 Oct

AI Scan for PRs

Covers what CodeQL doesn't: PHP, Shell, Terraform, Dockerfiles and more. Advisory; never blocks a merge.13

Preview · 28 Oct

Code scanning for AI apps

Flags indirect prompt injection, sensitive data disclosure and excessive agency.14

Dependency review

Shows the impact of dependency changes, and vulnerable versions, before you merge.3

03After merge

Copilot Autofix

Generates fixes for code scanning alerts.3

GA · 15 Oct

Agentic autofix

Assign an alert to Copilot: it fixes, re-runs CodeQL and opens a draft PR. Up to 25 alerts per PR.15

Preview · 28 Oct

AI Scan for repositories

An agentic scan of the whole default branch that skips what CodeQL already reports.16

Preview · 28 Oct

Reachability analysis

Gives Dependabot alerts a verdict: Reachable, Potentially reachable or Unreachable. JavaScript and TypeScript.17

04At scale

Security campaigns

GA · 16 Oct

License compliance

Auto-triage rules

Rules that ignore, snooze or fix Dependabot alerts for you.3
