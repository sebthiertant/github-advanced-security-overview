# GitHub Advanced Security: a two-minute product map

A short, print-style page for customer conversations. Since April 2025, GitHub Advanced Security is two standalone products, shown side by side as tiles along one developer path (while coding, before merge, after merge, at scale):

- **GitHub Secret Protection**: detect and prevent secret leaks
- **GitHub Code Security**: find and fix vulnerabilities

**Live page:** https://sebthiertant.github.io/github-advanced-security-overview/

## What's on the page

1. **Fig. 1**: the headline features of both products, laid out as one developer path.
2. **01 Secret Protection**: scan on demand, push protection, secret scanning, public monitoring and more, as tiles by stage.
3. **02 Code Security**: code scanning, AI Scan, Copilot Autofix and agentic autofix, reachability analysis, security campaigns and more, as tiles by stage.
4. **03 Around both products**: what every plan already includes, what the two products share, and how they cover AI agents.

Each tile carries a **GA** or **Preview** label with a date when the feature is recent. Use **Save as PDF** in the page header to get a short A4 handout.

## Sources and caveats

Every claim is numbered and linked to a public source at the bottom of the page: GitHub Docs, the GitHub product pages and the GitHub Changelog.

- Status labels are as of 19 Nov 2026. Previews can change before general availability, and some are off by default.
- Availability varies by plan and deployment (GitHub Enterprise Cloud, github.com only, GitHub Enterprise Server). Check the linked docs before quoting.
- It shows headline features, not every capability.
